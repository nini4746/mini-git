# 0005. checkout은 detached HEAD와 복원/덮어쓰기만

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
checkout은 커밋의 tree로 작업 파일을 되돌린다. branch 기능은 범위 밖이다.
대상 커밋에 없는 파일까지 지우려면 index와 대조하는 로직이 커진다.

## 결정
- `minigit checkout <commit-sha>`는 tree를 재귀 순회해 파일을 만들거나 덮어쓴다. 필요한 디렉토리를 만든다.
- 100755면 `0755`, 아니면 `0644`로 `chmod`한다.
- `.git/HEAD`에 커밋 해시를 직접 기록한다 (detached HEAD).
- 40자가 아닌 인자, 없는 해시, commit이 아닌 오브젝트는 tree 순회 전에 거부한다. 작업 파일은 바뀌지 않는다.
- 대상 커밋에 없는 파일은 지우지 않는다. index도 갱신하지 않는다.

## 대안
- 브랜치 전환: branch 기능이 범위 밖이다.
- stale 파일 삭제: index 대조 로직이 커진다.

## 결과
- 장점: 구현이 단순하다. 사용자 파일을 지우지 않는다.
- 단점/감수한 점: checkout 후 작업 트리에 이전 커밋의 파일이 남을 수 있다. index는 checkout 전 상태로 남는다.
