# 0002. SHA-1 직접 구현 (RFC 3174)

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
모든 오브젝트는 내용의 SHA-1 해시로 이름이 붙는다. 해시는 content-addressable storage의 핵심이라 학습 대상에 넣었다.
git 기본 오브젝트 포맷은 아직 SHA-1이다.

## 결정
- `src/sha1.c`에 RFC 3174 기반 SHA-1을 직접 구현한다.
- `minigit sha1-test`로 테스트 벡터를 자가 검증한다 (`"abc"` → `a9993e364706816aba3e25717850c26c9cd0d89d`).

## 대안
- 라이브러리 (OpenSSL 등): 학습 목적에 맞지 않는다.
- SHA-256 오브젝트 포맷: git 기본이 아직 SHA-1이고, 호환 목표에는 SHA-1이면 충분하다.

## 결과
- 장점: 해시 계산 과정을 직접 구현한다. 의존성이 늘지 않는다.
- 단점/감수한 점: 구현 정확성은 테스트 벡터와 git 해시 비교로만 보장한다.
