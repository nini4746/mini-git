# 0008. checkout에서 안전하지 않은 tree 엔트리 이름 거부

- 상태: 채택
- 날짜: 2026-07-14

## 맥락
checkout은 tree 엔트리 이름을 작업 트리 아래 경로로 그대로 썼다.
조작된 tree에 `../evil`, 절대 경로, `.git` 같은 이름이 있으면 저장소 밖에 쓰거나 `.git`을 덮어쓸 수 있었다.

## 결정
- tree 엔트리 이름은 하나의 안전한 경로 구성 요소여야 한다.
- 빈 이름, `/` 포함, `.`, `..`, `.git`이면 `fatal: unsafe tree entry name`으로 종료한다 (`src/main.c`).

## 대안
- 검증 없이 쓰기: path traversal로 저장소 밖이나 `.git`에 쓸 수 있다.

## 결과
- 장점: 작업 트리 밖이나 `.git`에 쓰지 않는다.
- 단점/감수한 점: 오류는 순회 중에 발생하므로, 앞선 엔트리는 이미 써졌을 수 있다.
