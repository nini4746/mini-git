# 0006. 테스트는 셸 스크립트로 진짜 git과 비교

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
목표가 git 호환성이라 git의 출력이 기준이다. 구현이 git을 호출하면 호환성을 증명할 수 없다.
zlib 압축 바이트는 압축 레벨에 따라 달라질 수 있다.

## 결정
- `tests/run.sh`와 스위트 `01`~`05`로 같은 입력을 minigit과 git에 넣고 결과를 비교한다. `make test`로 실행한다.
- 오브젝트는 `python3`의 `zlib.decompress`로 압축을 푼 뒤 내용을 비교한다.
- 구현 (`src/`)에서는 git을 호출하지 않는다. `run.sh`가 이를 검사한다.

## 대안
- C 단위 테스트: 호환성의 기준인 git 출력과 직접 비교하지 못한다.
- 압축 바이트 비교: zlib 레벨에 따라 결과가 달라질 수 있다.

## 결과
- 장점: `git log`, `git fsck --strict`, 오브젝트 집합 비교로 완료 조건을 자동 판정한다.
- 단점/감수한 점: 테스트에 `git`과 `python3`가 필요하다.
