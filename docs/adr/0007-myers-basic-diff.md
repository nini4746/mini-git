# 0007. Myers diff 기본형 (trace 저장 후 역추적)

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
diff는 선택 기능이다. 두 파일의 라인 단위 최단 편집 스크립트를 얻으면 충분하다.

## 결정
- `src/diff.c`에 O(ND) Myers 기본형을 구현한다. 깊이 `d`마다 `v` 배열 스냅샷을 `trace[d]`에 저장하고 역추적한다.
- 출력은 `-`/`+` 형식이다. unified diff 헤더와 hunk 병합은 하지 않는다.

## 대안
- linear space 개선판: 선택 기능이고 기본형으로도 최소 편집 수를 얻을 수 있다.

## 결과
- 장점: 구현이 짧고 알고리즘을 그대로 따라간다.
- 단점/감수한 점: 깊이마다 배열을 복사해 메모리를 더 쓴다. git diff 형식과 같지 않다.
