# 0001. C로 구현하고 외부 의존성은 zlib만 사용

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
git의 오브젝트, index, refs는 바이트 단위 포맷이다. 목표는 이 포맷을 직접 다루며 배우는 것이다.
loose object는 zlib으로 압축되는데, deflate까지 직접 구현하면 범위가 크게 늘어난다.

## 결정
- 언어는 C, 빌드는 `Makefile` (`cc -Wall -Wextra -std=c11 -O2`).
- 외부 의존성은 시스템 zlib 하나 (`LDLIBS = -lz`). 압축은 `compress2`, 해제는 `inflate`를 쓴다.
- 파일은 전체를 메모리로 읽는다. 대상 파일은 수 MB 이하로 가정한다.

## 대안
- 고수준 언어: 바이트 포맷을 직접 다루는 학습 목적에 맞지 않는다.
- deflate 직접 구현: 범위가 크게 늘어난다.
- 스트리밍 처리: 학습용이라 필요하지 않다.

## 결과
- 장점: 의존성이 zlib 하나라 빌드가 단순하다. 포맷을 바이트 단위로 직접 구성한다.
- 단점/감수한 점: 대용량 파일은 메모리에 한 번에 올라간다. 경로와 이름에 고정 크기 버퍼를 쓴다.
